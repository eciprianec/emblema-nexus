# Identidad de Marca: Emblema Nexus

## Visión Corporativa
**Emblema Nexus** — *Plataforma Integral de Gestión Empresarial*
Un sistema B2B formal, empresarial, que proyecta solidez técnica, transparencia legal y orden financiero.

## Paleta de Colores
Diseñada con Tailwind CSS v4, orientada al profesionalismo corporativo y lectura prolongada sin fatiga:
- **Principal (Slate/Pizarra)**: Base neutral para fondos y paneles. (`bg-slate-50`, `bg-slate-900`)
- **Acento Primario**: Azul marino o Azul Acero.
- **Minimalismo Cromático**: El uso del color está estrictamente reservado para acciones semánticas (Éxito = Verde, Error = Rojo, Peligro = Naranja/Rojo).

## Tipografía
- **Sans Serif**: Inter o Roboto para interfaz general, enfocado en alta legibilidad y soporte tabular para datos numéricos.
- **Monospace**: JetBrains Mono o similar para vista de logs, JSON, XML o identificadores fiscales (RNC/e-CF).

## Voz y Tono de la UI
- Estrictamente profesional, lenguaje formal.
- Español de negocios en todos los textos de la interfaz.
- Botones de acción claros y descriptivos: "Guardar Cambios" en lugar de "OK", "Autorizar Emisión" en lugar de "Proceder".

## Configuración PWA
- `manifest.json`: Nombre corto "Nexus".
- Iconos minimalistas en monocromo o duotono.
- Colores de tema coincidiendo con la paleta principal oscura/clara para transiciones nativas suaves en el navegador.
